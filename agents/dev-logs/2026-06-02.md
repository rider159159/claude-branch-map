- **Q**:CLAUDE.md 怎麼整合 agents/?(保留現有 + 開頭引導 / 重寫 / 完全分離)
- **A**:保留現有 CLAUDE.md + 開頭加「0. 起手式」引導。理由:既有 Electron 三層細節(IPC 通道、JSONL 格式、分支匹配)都在 CLAUDE.md,重寫一份等於同步成本翻倍。

- **Q**:優化規格寫多細?(完整 brief / 簡版規劃 / 只寫 Top 3)
- **A**:完整 brief(每點含 Context / 既有行為 / Goal 或變更內容 / Scope / Backward compat / Acceptance / Non-goals)。理由:這份本來就是要當 task brief 用,簡版到時候還要再展開。

- **Q**:dev-log 紀律強度?(只存今日 / 加 CLAUDE.md 提醒 / 加 stop hook)
- **A**:只存今日。理由:個人專案,使用者本人會盯,不需要 hook 自動化。日後若紀律掉了再考慮加。

- **Q**:Phase 1 是否保留 Cursor 編輯器支援?(保留 / 移除聚焦 Claude / 改成插件式架構)
- **A**:**移除**,專注在「本 app 對 Claude 擴充的應用」。理由:本 app 的差異化價值是「session ↔ 分支」對應與 Claude hook 整合,不是「多編輯器啟動器」。砍 Cursor 把資源放回 Claude 工作流。Phase 1 的「明確不做」改成「不做 Cursor 或其他編輯器支援」,連帶簡化 #8 不再要求動態標籤。

- **Q**:#2 那 30 分鐘的預算挪到哪?(hook 健康檢查 / session 對應 commit / 不替補 / 全部重排)
