### 決策 / 取捨

- icon button 預設背景一律 `transparent` + `border: 1px solid transparent`,**不可給實體背景**。理由:即使父層 opacity 0,按鈕本體有實體背景時 transition 動畫期間會閃,且使用者觀感上「常駐」。已寫進 [ux-patterns.md](../../.claude/skills/ux-patterns.md) 1.2 節作為強制規範
- 新顏色 `--error-soft` 從 `--error` 的真實 rgb 推導(rgb(248, 81, 73)),不沿用先前錯誤的 rgb(248, 113, 113)。理由:同畫面出現兩種紅是視覺 bug,且原本的 rgb(248, 113, 113) 不在 token 表上、沒有單一來源
- `.branch-badge.confidence-low` 邊框的螢光黃 rgb(250, 204, 21, 0.4) **保留不動**。理由:design-system.md 第 3.3 節已明文「邊框是降飽和的黃,非 `--low` 本色」,屬刻意設計
- settings input 系列的 `:focus`(非 `:focus-visible`)**保留不動**。理由:`:focus-visible` 對原生 input 在某些瀏覽器行為不一致,且這裡只改 `border-color` 不會殘留醜框,實務上不算違規
- 「在 VS Code 繼續對話」用 button 文字 + disabled,不用 spinner。理由:符合 ux-patterns.md「能用 skeleton 就用 skeleton,沒結構就退回文字」+ 沿用 App.tsx `重新整理` 按鈕同 pattern。spinner 在這個 app 已被全面禁用
